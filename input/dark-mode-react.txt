You turn on dark mode. The background goes black. But the text is still dark gray, so nothing is readable.

Why does this happen? Most apps change only the background. The text and cards keep their hard-coded colors.

The fix is one rule: colors come from one place.

Put every color in a CSS variable at the root. Define the dark values under data-theme dark. Your components only use the variables, never a fixed color.

Add a toggle. Save the choice in local storage, wrapped in try and catch, because storage can fail. Use the system setting as the default.

The takeaway: if a color is written in two places, one of them will be wrong.
