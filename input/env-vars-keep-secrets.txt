You pushed your API key to GitHub, and now anyone can read it. Here is how to keep secrets out of your code.

A secret, like an API key or a database password, should never live inside your code.

Store it in an environment variable instead, set on your machine or on your hosting service.

Your code reads it at runtime, so the same code runs everywhere.

Add your dot env file to gitignore, so git never commits it.

Share an example file with fake values.

If a key leaked, rotate it: create a new one, then revoke the old one.

Takeaway: code gets shared, secrets do not.
