Your login fails with "Failed to fetch." So what's wrong?

The browser is blocking the request. Your app and your API run on different addresses. The browser only lets the answer through if the API allows your app's address.

Open the console. You'll see "blocked by CORS policy." That's the real reason.

For example, the API allows port 3000, but your app runs on 5173. So the call is blocked.

The fix: add your app's real address to the API's allowed list. Then show a friendly message for network errors, not raw browser text.

Long term, keep allowed addresses in a config file, not in code.

The rule: when you see "Failed to fetch," open the console first.
