You paste the same rules into Claude every week. Write them once instead.

A Claude skill is a folder with one file inside, SKILL dot md, full of instructions for one task.

At the top sit two lines: a name, and a description that says when to use it.

Those two lines are always loaded, so Claude knows the skill exists. The rest loads only when your task matches the description.

Example: a release notes skill that knows your format and lists breaking changes first.

Takeaway: put a routine you repeat into a skill, not into every new chat.
