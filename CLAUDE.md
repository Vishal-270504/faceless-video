# Faceless Shorts Factory

Makes faceless YouTube Shorts (max 60 s, 1080x1920) entirely on this PC, free:
script -> narration (Kokoro TTS, local) -> word timings (faster-whisper, local) -> captions + audio in a HyperFrames composition -> MP4.

## Folders
- `input/` - one script per video, plain text: `input/<name>.txt` (spoken words only, no stage directions)
- `output/audio/` - narration WAVs (generated)
- `output/timings/` - word timing JSON (generated)
- `output/video/` - final MP4s (copy here after render)
- `assets/music/`, `assets/broll/` - optional royalty-free files you add yourself
- `video-project/<name>/` - HyperFrames composition per video (generated by script, editable)
- `scripts/` - `make_voice.py`, `build_short.py`
- `.venv/` - Python env (kokoro, torch CPU, faster-whisper, soundfile, numpy)

## Pipeline (run in this order)
1. Write `input/<name>.txt` (or the `script-writer` agent does).
2. `.venv\Scripts\python scripts\make_voice.py input\<name>.txt [voice] [speed]`
   - default voice `af_heart`, speed `1.0`. Prints duration; must say OK (<= 60 s).
3. `.venv\Scripts\python scripts\build_short.py <name> "Optional title card"`
4. `cd video-project\<name>` then `npx --yes hyperframes@0.9.26 render` (about 2-6 min for a 60 s Short). The MP4 lands in `video-project\<name>\renders\`; copy it to `output\video\<name>.mp4`.
5. Check: `npx hyperframes preview` only if the user asks to look at it.

Rule: use the scripts. Do not hand-write captions or timings.

## Token-saving rules (apply to every agent)
- Do not read whole generated files (WAV, timings JSON, MP4, large HTML). Use the one-line script output.
- Do not re-read a script or composition you just wrote.
- Keep scripts short; the timings JSON is the only data passed between steps.
- Scripts are the cheap path. Write new HTML by hand only for a visual that the scripts do not cover.
- One render per video unless something broke.

## Quality defaults
- Script: 90-140 spoken words (about 40-55 s), hook in the first 2 seconds, one idea, short sentences, no filler.
- Captions: 3 words per card, uppercase, big, centred in the lower-middle area.
- Audio: 24 kHz mono Kokoro output. Do not add music unless a file exists in `assets/music/`.

## Agents (in `.claude/agents/`)
- `script-writer` - writes `input/<name>.txt` from the user's topic or transcript.
- `voice-producer` - runs `make_voice.py` and reports the one-line result.
- `video-builder` - runs `build_short.py`, renders with HyperFrames, copies the MP4 to `output/video/`.

Run them in that order. The main session coordinates and reports; it does not do the agent's job itself.

## Reference
- HyperFrames skills: `/hyperframes`, `/hyperframes-cli`, `/media-use` (read only if a step fails or a new visual is needed).
- Install commands: see the Install section at the bottom of this file.

## Install (already done; for a fresh PC)
- Node.js 22+, FFmpeg on PATH, Python 3.12.
- `python -m venv .venv` then `.venv\Scripts\python -m pip install torch --index-url https://download.pytorch.org/whl/cpu kokoro soundfile faster-whisper numpy`
- First run downloads the Kokoro model (~330 MB) and Whisper `base.en` (~150 MB) once; afterwards it works offline.
